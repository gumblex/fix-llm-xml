## 1.2

- 假设：**纯文本标签中的真实同名标签、上级标签文本必须已转义或放入 CDATA**。  
  行为变化：纯文本标签全程按普通 XML 实体转义，不再识别内容中途的 CDATA；开始标签后紧跟兼容 CDATA 前缀时，强制进入 CDATA 模式，且不再检查该标签是否在 `text_tags` 名单中。

- 假设：错误关闭、未命中关闭通常只是局部错误，**不应吞掉后续有效 XML**。  
  行为变化：未命中关闭标签会根据后续是否还存在自己的关闭标签，决定“忽略”还是“隐式关闭当前层”；只有隐式关闭节点参与同名拆分，合法同名嵌套保持不变。

- CDATA 关闭与序列化规则规范化  
  行为变化：CDATA 起始标签关闭按优先级处理：先精确匹配 `]]></name>`，再识别疑似 CDATA 结束残留 + `</name>`，最后退回普通 text_tag 规则；输出统一为标准 CDATA；内容中的裸 `]]>` 转为安全形式；已合法转义的 CDATA 序列不二次转义；关闭前紧邻的疑似 `]]>` 残留会被删除；普通结构节点中的原生合法 CDATA 段保持原样。

- **新增标签属性、注释语法修复**  
  行为变化：未闭合属性引号自动补全；无引号属性值自动加引号；属性名中的误加引号、非法字符自动清洗；属性值中的 `<`、`>`、`"`、`&` 自动转义；重复属性保留第一个；结束标签上的属性全部删除；注释也会被规范化为合法 XML 注释。

- **根节点异常关闭保护**  
  行为变化：最外层根节点的关闭按“从后往前固定位置”处理；文档中间出现的根关闭视为异常关闭，不直接关闭根节点，避免整个文档被误伤。
